
## ✅ **inverse.css** - Color Inversion & High Contrast
- **Base inverse utilities** for dark backgrounds/light text
- **Component overrides** - ensures buttons, forms, cards work in inverse contexts
- **Section utilities** - full-width inverse sections
- **Gradient backgrounds** - multiple gradient options
- **High contrast utilities** for accessibility
- **Accessibility support** - respects user preferences for contrast/motion

## 🎯 Key Hugo Integration Features

Inverse CSS follows the project's established patterns:

**✅ Utility-First Approach** - Maximum flexibility for Hugo developers
**✅ Design Token Integration** - All utilities use your CSS custom properties
**✅ Modern CSS Techniques** - `clamp()`, CSS Grid, logical properties
**✅ Accessibility First** - Proper contrast, focus styles, motion preferences
**✅ Hugo Template Ready** - Perfect for partials and shortcodes
