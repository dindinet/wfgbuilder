# Developer Guide: Advanced Page Builder

This project utilizes a modular architecture to integrate Hugo with DecapCMS, enabling a flexible "Page Builder" experience. This guide explains how the system works and how to extend it with new sections.

## How It Works: The Build Process

The system is designed to be "self-healing" and automated. Instead of manually updating multiple configuration files, the build process dynamically generates the necessary configurations for DecapCMS based on the files present in your project.

### 1. Dynamic DecapCMS Configuration

The `admin/config.yml` file is not static. It is generated by Hugo during the build:

- **Source**: Hugo reads individual YAML configuration files located in `data/decap/sections/`.
- **Process**: A Hugo template iterates through these files and merges their field definitions into the main `sections` widget of the `advanced` page collection.
- **Result**: When you add a new YAML file to the data folder, the CMS automatically recognizes the new section type without manual config updates.

### 2. Dynamic Preview Bundling

To ensure the CMS preview pane matches the live site, we use Hugo's Asset Pipeline to bundle React/Preact preview components:

- **Source**: The build script looks for JavaScript/JSX files in `assets/js/decap-previews/`.
- **Process**: Using `resources.Match`, Hugo finds all preview files. A main entry script dynamically imports them and registers them with `CMS.registerPreviewTemplate`.
- **Result**: Hugo bundles these components into a single JavaScript file. When you add a new JS file to the previews folder, it is automatically included in the CMS bundle.

### 3. CSS Injection

- **Source**: Section-specific styles in `assets/css/sections/` (and the main framework CSS).
- **Process**: These are bundled by Hugo Pipes.
- **Result**: The CSS is injected into the CMS preview iframe, ensuring high-fidelity previews.

## How to Add a New Page Section

To add a new section (e.g., a "Testimonial" section), you need to create four files. The system relies on naming conventions to tie these together.

### Step 1: Define CMS Fields (YAML)

Create a file to define the fields content editors will see in DecapCMS.

**File:** `data/decap/sections/testimonial.yml`

```yaml
name: Testimonial
label: Testimonial Section
widget: object
fields:
  - {label: "Quote", name: "quote", widget: "text"}
  - {label: "Author", name: "author", widget: "string"}
  - {label: "Portrait", name: "image", widget: "image", required: false}
```

### Step 2: Create Hugo Partial (HTML)

Create the template that renders the section on the live website. The section data is passed as the context (`.`).

**File:** `layouts/partials/Testimonial.html`

```html
{{ $section := . }}
<section class="section-testimonial">
  <div class="container">
    <blockquote>
      <p>"{{ $section.quote }}"</p>
      <footer>
        {{ if $section.image }}
          <img src="{{ $section.image }}" alt="{{ $section.author }}" class="avatar">
        {{ end }}
        <cite>— {{ $section.author }}</cite>
      </footer>
    </blockquote>
  </div>
</section>
```

### Step 3: Create CMS Preview (JS/JSX)

Create a component to render the preview in the CMS admin panel. The props passed to this component match the fields defined in Step 1.

**File:** `assets/js/decap-previews/TestimonialPreview.js`

```javascript
const TestimonialPreview = (props) => {
  // Props contain the data fields and the 'h' (hyperscript) function
  const { quote, author, image, getAsset, h } = props;

  return h('section', { className: 'section-testimonial' },
    h('div', { className: 'container' },
      h('blockquote', null,
        h('p', null, `"${quote || ''}"`),
        h('footer', null,
          image ? h('img', { src: getAsset(image).toString(), className: 'avatar' }) : null,
          h('cite', null, `— ${author || ''}`)
        )
      )
    )
  );
};

export default TestimonialPreview;
```

### Step 4: Add Styles (CSS)

Add any specific styles required for this section.

**File:** `assets/css/sections/testimonial.css`

```css
.section-testimonial blockquote {
  font-size: 1.25rem;
  font-style: italic;
  text-align: center;
}

.section-testimonial .avatar {
  width: 50px;
  height: 50px;
  border-radius: 50%;
  margin-right: 10px;
  vertical-align: middle;
}
```

### Final Step

Run your Hugo server (`hugo server`). The new section will automatically appear in the "Add Component" dropdown within the DecapCMS editor for pages using the Advanced layout.
